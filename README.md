Projeto CRUD para mercado:  
Aplicação web desenvolvida em PHP utilizando Orientação a Objetos e conexão com banco de dados MySQL via PDO.  
** SOBRE O PROJETO **  
Este projeto foi construído "na unha" (sem a utilização de frameworks ou padrões MVC) com o objetivo de demonstrar a manipulação de dados MySQL utilizando PHP nativo e boas práticas de conexão via PDO.  
** FUNCIONALIDADES **
-> Cadastro e atualização de produtos (ex.: controle de estoque, valor unitário e total).  
-> Consulta e listagem de registros.  
->Exclusão de itens.  
** TECNOLOGIAS UTILIZADAS **  
-> PHP (Orientação a Objetos).  
-> MySQL (Banco de dados).  
-> PDO ( PHP Data Objects para persistência segura).  
-> HTML5 / JS básico.
